PlusMagi Markdown is a WordPress plugin for adding Markdown-based content workflows and editor enhancements.

== Description ==

PlusMagi Markdown provides a streamlined experience for working with Markdown content inside WordPress and the Gutenberg editor.
It adds a simple, focused content workflow for authors who prefer Markdown while keeping the WordPress editing experience intact.

== Features ==

* Markdown-friendly content workflow
* Gutenberg-friendly editor integration
* Lightweight plugin structure for easy maintenance
* Simple installation and activation process

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/plusmagi-markdown` directory
2. Activate the plugin through the 'Plugins' screen in WordPress
